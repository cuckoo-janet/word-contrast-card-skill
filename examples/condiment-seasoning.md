# Example — condiment / seasoning

## Input

```text
condiment / seasoning
```

## 语义设定

两个词都与调味有关。以下区别选取最容易画出来的常见情境，并非绝对的使用时间界限：`seasoning` 也可以在上桌后添加。

### condiment
- 常见中文：佐餐调味品
- 核心关注点：成品食物旁供人搭配食用的调味品
- 一句话区别：常指番茄酱、芥末酱等与现成食物一起提供、由食用者蘸取或添加的东西。
- 最适合画的场景：一根薯条蘸进一小碟番茄酱。
- 视觉关键词：现成食物、蘸酱、搭配食用
- 看到什么情况最容易想到这个词：薯条旁放着一小碟番茄酱。

### seasoning
- 常见中文：烹饪调味料
- 核心关注点：为了给食物调味而加入的配料
- 一句话区别：常指盐、胡椒、香料等用于改变或增强食物味道的配料。
- 最适合画的场景：从调味罐把调料撒进正在做的食物中。
- 视觉关键词：撒入、食物、调味过程
- 看到什么情况最容易想到这个词：做菜时往锅里的食物加入调料。

## 核心对比

- condiment = 吃时搭配
- seasoning = 做时调味

## 图片提示词

依据 [`assets/image-template.md`](../assets/image-template.md) 制作一张 3:4 竖版英语词义辨析手绘卡，上下两个等高区域，分别展示 `condiment` 和 `seasoning`。暖白色背景，大量留白；每个区域各有一圈完整、细的圆角边框，边框之间有白色间距。上区的边框、英文词背后的有机马克笔色斑、核心短语高亮只使用同一种柔和浅蓝色；下区相应位置只使用同一种柔和浅绿色。其他部分只用近黑线稿和白色，**食物、酱料、调味罐、锅及人物不得上色**。英文主题词为醒目的粗笔画小写手写字，中文清晰可读，英文搭配较细。每一行文字都水平、正面朝向读者。

- 上区 `condiment`：只画一根薯条蘸进一小碟番茄酱；用无填色轮廓表示酱料，不画桌面或其他食物。
- 下区 `seasoning`：只画一只无字调味罐，把黑色小点状调料撒进一小锅食物；不画厨房背景或其他器具。

逐字复制上方**文字锁定清单**，不得增加标题、数字、标牌、徽标、水印或插图中的文字。仅在 `重点是：` 后面的核心短语上使用本区颜色的高亮。场景和文字都不得增删或改写。
