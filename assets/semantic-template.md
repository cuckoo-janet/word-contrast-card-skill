# Semantic Analysis Template

分析以下易混或近义英文词：

`{{WORDS}}`

目标：不是堆砌词典释义，而是提炼最适合做视觉辨析卡片的**核心语义差异**。

先把全部单词放在同一个语义空间中比较，再逐词输出；不要先按未来图片分组分析。

对每个单词重复以下结构：

## {word}

- 常见中文：
- 核心关注点：
- 一句话区别：
- 最适合画的场景：
- 视觉关键词：
- 看到什么情况最容易想到这个词：

最后输出：

## 核心对比

- `{word 1}` = `{2～6字核心词}`
- `{word 2}` = `{2～6字核心词}`
- `...`

要求：

- 不堆砌释义，不讲复杂语法，不展开词源。
- 优先体现英语实际使用时的“关注点差异”。
- 每个词尽量对应一个“一眼能画出来”的视觉场景。
- 场景之间必须体现不同的动作、关系、位置、过程或结构，不能只是换一个物体。
- 核心对比标签要互相区分，避免近义改写。
- 核心对比标签按语义自然使用 2～6 个汉字；2 个字或 3 个字已经准确时，不要为了凑 4 个字而加词。
- 如果这些词并非严格近义词，不要强行视为同义词；说明真实关系，并提炼最常见的混淆点。
- 内容尽量简洁，服务于后续视觉化。
